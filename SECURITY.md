# Security and sensitive research data

The public reference examples in this repository are synthetic and should remain so. Do not include cloud credentials, customer records, proprietary source snippets, prompts containing personal information, private agent traces, or real billing exports in issues or pull requests.

The included validator is a research starter and **does not** enforce runtime agent authorization or certify a modeled application's security. Use independent policy enforcement, threat modeling and verification for any live deployment.

Before opening this repository to external contributors, the maintainers should publish a private vulnerability-reporting channel and a disclosure response policy. Until that exists, avoid posting exploit details or sensitive findings publicly. Contact the repository owners through an established private institutional channel if one is available.
